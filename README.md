# AERONAUT flight simulator

[Play the game](https://hackyult.github.io/?v=119)

Release `v0.1.119` includes reconstructed factory-style liveries for the 737-800, 777-300ER and A350-900, repaired 737 crown coverage, corrected A350 tail paint projection and visual clearance for internal upper gear attachments. Satellite terrain has outward-facing seam walls and narrow top lips. The 26 focused terrain loading, continuity and seam checks pass.

The verified release archive is attached to the release. GitHub Actions checks its SHA-256 and publishes the static game through GitHub Pages. Release 118 flight dynamics, DEM lookahead, weather, airports and aviation charts are retained.

Flight dynamics remain a simplified game model, not certified aircraft performance. Reconstructed output texture dimensions do not imply new manufacturer CAD or 8K photographic source detail. OpenFlightMaps coverage is regional; FAA charts cover the United States.

Game source, model source packages, attribution and restoration scripts are included at `dist/sources/` and [/sources/](https://hackyult.github.io/sources/). Consult `ATTRIBUTION.md` for each asset's licence. This game includes assets restricted to noncommercial use; no single blanket licence replaces individual asset licences.

No account credentials or private server are required to play. Public imagery and chart services require an internet connection.

# AERONAUT flight simulator

[Play release 133](https://hackyult.github.io/?v=133) · Default VNKT → ZULS.

Release 133 repairs arrival loading with real parent-image fallback and bounded preloading, adds obstacle-checked lateral tug approaches and departures, 52 mapped VNKT taxiways, timed terrain-image transitions, and 16 original terminal structures at 15 airports. Potala Palace receives documented footprint and dimension calibration.

[Coverage, source dates, checks and limitations](https://hackyult.github.io/sources/release133/).

All 1,095 runway-equipped airports have coverage-plan and five-jet short-pushback geometry checks. Source-authored structures cover 75 airports; 111 have packaged models including footprint-derived structures. Mapped centreline data covers 383 airports, while 58 currently pass complete automatic-route checks. Exact current terminal replication and surveyed satellite alignment are not claimed.

Prior scenery and continuous-flight updates are retained.

# AERONAUT flight simulator

[Play the game](https://hackyult.github.io/)

The verified release archive is attached to release `v0.1.117`. GitHub Actions checks its SHA-256 and publishes the compiled static game through GitHub Pages. The website uses the domain root so its aircraft, cockpit, imagery and navigation data paths resolve correctly.

Release 117 includes A380 flap/root cleanup, moderate wind, damped load-driven wing movement, terrain seam protection, airport detail and lighting refinements, and FAA / OpenFlightMaps aviation chart layers. Aircraft data and flight response remain simulation approximations, not certified flight or maintenance models. OpenFlightMaps coverage is regional; FAA charts cover the United States.

Game source, model source packages, attribution and restoration scripts are included in the archive at `dist/sources/` and are also served at `/sources/`. Consult `ATTRIBUTION.md` for each asset's licence. This game includes assets restricted to noncommercial use; no single blanket licence replaces the individual asset licences.

No account credentials or private server are required to play. Public third-party imagery and chart services may require an internet connection.

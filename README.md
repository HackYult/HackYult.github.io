# AERONAUT flight simulator

[Play release 140](https://hackyult.github.io/?v=140) · Default VNKT → ZULS.

The route chart is now a persistent dock below the right navigation map. Its + / − button expands or minimizes the map preview without removing the header. The arrow opens all navigation controls in a half-screen window; reducing restores the dock. [Layout checks](https://hackyult.github.io/sources/release140/).

Release 139 Apple aircraft compatibility and compact approach overlays are retained. Physical iPad validation remains outstanding.

595 airports have public chart / agency links; 510 list direct PDFs, totaling 11,709 document links. Imported procedure references cover 112 in-game airports, including 109 with approach references. [All-airport coverage and gaps](https://hackyult.github.io/sources/release138/coverage.html).
